# Home

`Home.razor` - главная страница хранилища.

## Назначение

Страница отображает и редактирует три типа записей:

- пароли (`PasswordEntry`);
- банковские карты (`CardEntry`);
- заметки (`NoteEntry`).

Данные читаются и сохраняются через `SecureRepository<T>`.

## Зависимости

- `IJSRuntime` - фокусировка скрытых полей карточки;
- `VaultSessionService` - загрузка данных после авторизации;
- `SecureRepository<PasswordEntry>`;
- `SecureRepository<CardEntry>`;
- `SecureRepository<NoteEntry>`.

## Загрузка данных

`OnInitialized()` подписывается на `VaultSession.StateChanged`. Если пользователь уже авторизован, вызывается `LoadData()`.

`LoadData()` получает записи из трех репозиториев через `getAll()` и сортирует их по `Title`.

При уничтожении компонента `Dispose()` снимает подписку с `VaultSession.StateChanged`.

## Добавление и редактирование

Форма поддерживает типы `Password`, `Card`, `Note`. При редактировании тип записи менять нельзя.

`SaveItem()` вызывает один из методов:

- `SavePasswordAsync()`;
- `SaveCardAsync()`;
- `SaveNoteAsync()`.

После сохранения данные перечитываются и форма закрывается.

## Правила сохранения

Для пароля обязательны `title` и `login`. Если `serviceName` пустой, используется `title`.

Для карты обязательны `cardTitle` и `cardNumber`. Номер карты сохраняется только цифрами. Владелец, срок и CVV сохраняются после нормализации ввода.

Для заметки должен быть заполнен заголовок или текст. Если заголовок пустой, используется значение `Новая заметка`.

При создании ID выбирается как максимальный существующий ID плюс один.

## Просмотр деталей

Для каждой записи открывается детальное окно. Пароль и CVV скрыты по умолчанию и переключаются отдельными кнопками.

Из детального окна можно перейти к редактированию или удалить запись. Удаление вызывает `Remove(id)` и `Save()` соответствующего репозитория.

## Поиск и сортировка

Поиск работает по объединенному тексту записи:

- пароль: название, логин, сервис;
- карта: название, владелец, банк, номер карты;
- заметка: название и содержимое.

Фильтры: `all`, `password`, `card`, `note`.

Сортировка переключается между названием и типом. Для сортировки по названию дополнительно переключается направление.

## Карточная форма

Ввод карты использует отдельные обработчики:

- `OnCardNumberInput()` оставляет до 16 цифр и форматирует группами по 4;
- `OnExpiryInput()` оставляет до 4 цифр и форматирует `MM/YY`;
- `OnCvvInput()` оставляет до 3 цифр;
- `OnCardHolderInput()` обрезает пробелы по краям.

Фокус на скрытые поля выставляется через JS-функцию `bpFocus`.
