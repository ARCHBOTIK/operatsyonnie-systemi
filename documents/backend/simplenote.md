# SimpleNote

Файл `SimpleNote.cs` содержит класс `Note`.

## Назначение

`Note` - простая модель заметки с идентификатором и текстом.

## Свойства

- `Id` - идентификатор записи;
- `NoteText` - текст заметки.

## Важно

Имя файла и имя класса не совпадают: файл называется `SimpleNote.cs`, а тип в коде называется `Note`.

В текущем UI для заметок используется более новая модель `NoteEntry`. `Note` остается простой моделью из старого набора классов.
