# SimpleJsonRepository

`SimpleJsonRepository<T>` - простой JSON-репозиторий без шифрования.

## Назначение

Класс хранит список объектов `T` в JSON-файле через `FileWorker`. В отличие от `SecureRepository<T>`, данные не шифруются.

`T` должен реализовывать `IHasID`.

## Поля

- `_filename` - имя файла;
- `_items` - коллекция загруженных объектов.

## Загрузка

Конструктор сохраняет имя файла, создает пустой список и вызывает `Load()`.

`Load()` читает файл через `FileWorker.readFile()` и десериализует `List<T>`. Если файл отсутствует, используется пустой список.

Ошибки JSON, доступа и ввода-вывода преобразуются в `InvalidOperationException`.

## Методы

- `Save()` - сериализует коллекцию в UTF-8 JSON и записывает файл;
- `GetItemById(int id)` - возвращает запись по ID или `default`;
- `GetAll()` - возвращает все записи;
- `Add(T newItem)` - добавляет запись с проверкой уникальности ID;
- `Remove(int id)` - удаляет запись по ID;
- `Update(T newItem)` - заменяет запись с тем же ID.

## Ограничение

Класс не предназначен для хранения паролей, карт или заметок в рабочем хранилище, потому что не выполняет шифрование.
