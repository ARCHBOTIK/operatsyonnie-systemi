# SecureRepository

`SecureRepository<T>` - файловый репозиторий для зашифрованных коллекций.

## Назначение

Класс хранит список объектов `T` в JSON, шифрует файл через DEK из `keyManager` и загружает данные только когда хранилище разблокировано.

`T` должен реализовывать `IHasID`.

## Поля

- `_fileName` - имя файла в `FileSystem.AppDataDirectory`;
- `_keyManager` - источник DEK;
- `_items` - загруженная коллекция;
- `_isLoaded` - была ли коллекция загружена;
- `_loadedKeyVersion` - версия ключа, при которой коллекция была загружена.

## Загрузка

`EnsureLoaded()`:

1. Возвращает уже загруженные данные, если DEK не менялся.
2. Если DEK не загружен, очищает кэш и возвращает `false`.
3. Если DEK загружен, вызывает `Load()`, запоминает версию ключа и возвращает `true`.

`Load()` читает файл через `FileWorker.readFile()`, расшифровывает `EncryptionFunctions.DecryptData()` и десериализует JSON в `List<T>`.

Если файл не найден, коллекция становится пустой. Ошибки дешифрования и JSON преобразуются в `InvalidOperationException`.

## Сохранение

`Save()` требует разблокированное хранилище. Данные сериализуются в UTF-8 JSON, шифруются через `EncryptionFunctions.EncryptData()` и записываются через `FileWorker.writeFile()`.

## Операции

- `GetItemById(int id)` - возвращает запись по ID или `default`, если хранилище заблокировано;
- `getAll()` - возвращает все записи или пустую коллекцию, если хранилище заблокировано;
- `Add(T newItem)` - добавляет запись и проверяет уникальность ID;
- `Remove(int id)` - удаляет запись по ID;
- `Update(T newItem)` - заменяет запись с тем же ID;
- `DeleteDatabase()` - удаляет файл и очищает кэш.

Изменяющие операции вызывают `EnsureUnlocked()` и выбрасывают исключение, если DEK не загружен.
