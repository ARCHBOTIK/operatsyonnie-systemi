# SyncTransferMode

## Назначение

`SyncTransferMode` описывает направление операции синхронизации.

## Роль в системе

Перечисление используется в `TcpBridge` и `SyncOperationResult`, чтобы различать отправку и приём базы.

## Пространство имён / модуль

`SecurePassword`

Источник: `SecurePassword/SecurePassword/sql(rus)/NetworkProtocols/TcpBridge.cs`

## Значения

* `Upload` - локальная база отправляется на другое устройство.
* `Download` - локальное устройство принимает базу с другого устройства.

## Основные методы

Нет.

## Правила использования

* Использовать вместе с результатом операции синхронизации.
* Не хранить пользовательские сообщения в перечислении; для этого есть `SyncOperationResult.Message`.
