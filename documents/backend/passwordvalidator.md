# PasswordValidator

`PasswordValidator` - статический сервис оценки стойкости пароля.

## Назначение

Класс рассчитывает приблизительную энтропию, процент стойкости, уровень стойкости и проверяет пароль по встроенному списку распространенных паролей.

## Поля

- `_badPasswords` - лениво загружаемый кэш распространенных паролей;
- `SyncRoot` - объект синхронизации для загрузки и очистки кэша.

## Методы

### CalculateCryptographicStrength

`CalculateCryptographicStrength(string password)` возвращает уровень от 1 до 4:

- меньше 28 бит - `1`;
- меньше 44 бит - `2`;
- меньше 64 бит - `3`;
- 64 бита и выше - `4`.

### CalculateStrengthPercentage

`CalculateStrengthPercentage(string password)` переводит энтропию в процент. Энтропия ограничивается 80 битами.

### CalculateEntropyBits

`CalculateEntropyBits(string password)`:

1. Оценивает размер алфавита по типам символов.
2. Считает базовую энтропию как `length * log2(alphabet)`.
3. Вычитает штраф за повторы.
4. Вычитает штраф за последовательности.
5. Вычитает 18 бит, если пароль найден в списке распространенных.
6. Возвращает округленное значение не ниже 0.

### IsPasswordCommon

`IsPasswordCommon(string password)` загружает список из встроенного ресурса `badwords.txt` и проверяет пароль без учета регистра.

### ClearBadPasswords

`ClearBadPasswords()` очищает кэш списка распространенных паролей.

## Важно

Оценка является пользовательской подсказкой, а не строгим криптографическим доказательством стойкости.
