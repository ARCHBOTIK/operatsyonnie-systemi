# LoginInfo

`LoginInfo` - простая модель логина и пароля.

## Назначение

Класс хранит имя пользователя, пароль и идентификатор записи. Реализует `IHasID`.

## Свойства

- `Id` - идентификатор записи;
- `Password` - пароль;
- `Username` - имя пользователя или логин.

## Важно

В текущем UI для паролей используется более новая модель `PasswordEntry`. `LoginInfo` остается простой моделью из старого набора классов.
