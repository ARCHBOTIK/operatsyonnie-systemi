# CardInfo

`CardInfo` - простая модель банковской карты.

## Назначение

Класс хранит базовые числовые поля карты и реализует `IHasID`.

## Свойства

- `Id` - идентификатор записи;
- `CardNumber` - номер карты как `long`;
- `Cvc` - CVC-код;
- `YearExpired` - год окончания срока действия;
- `MonthExpired` - месяц окончания срока действия.

## Важно

В текущем UI для карт используется более новая модель `CardEntry`. `CardInfo` остается простой моделью из старого набора классов.
