# keyManager

## Назначение

`keyManager` управляет ключевым файлом `keys.dat`: создаёт DEK, выводит KEK из мастер-пароля через Argon2id, шифрует и расшифровывает DEK через AES-GCM, а также подготавливает ключевой файл для передачи профиля между платформами.

## Роль в системе

Вспомогательный криптографический класс. Он не хранит пользовательские записи, но отвечает за ключ, которым затем шифруются файлы паролей, карт и заметок.

## Пространство имён / модуль

`SecurePassword`

Источник: `SecurePassword/SecurePassword/sql(rus)/FileInputOutputClasses/keyManager.cs`

## Зависимости

* `EncryptionFunctions` - генерация соли, DEK, KEK и AES-GCM операции.
* `ArgonParameters` - параметры Argon2id.
* `OSType` - выбор платформенного набора параметров.
* `FileWorker` - чтение и запись `keys.dat`.
* `FileSystem.AppDataDirectory` - каталог хранения ключевого файла.

## Основные поля и свойства

* `KeyFileMagic`
  * Тип: `byte[]`
  * Доступ: `private static readonly`
  * Назначение: сигнатура переносимого формата ключевого файла.
* `TransferArgonParameters`
  * Тип: `ArgonParameters`
  * Доступ: `private static readonly`
  * Назначение: параметры Argon2id для экспортируемого ключевого файла. Сейчас используются Android-параметры, чтобы профиль, переданный с Windows, мог быть открыт на Android без тяжёлых Windows-настроек.
* `_keyFilePath`
  * Тип: `string`
  * Назначение: путь к ключевому файлу.
* `_salt`
  * Тип: `byte[]?`
  * Назначение: соль для вывода KEK.
* `_encryptedDek`
  * Тип: `byte[]?`
  * Назначение: зашифрованный DEK.
* `_dek`
  * Тип: `byte[]?`
  * Назначение: расшифрованный ключ данных текущей сессии.
* `_loadedPassword`
  * Тип: `string?`
  * Назначение: мастер-пароль активной разблокированной сессии, нужен для переупаковки DEK при экспорте и смене платформенных параметров.
* `KeyVersion`
  * Тип: `int`
  * Назначение: счётчик изменений состояния ключа.

## Основные методы

* `CreateKeyFile(string password)`
  * Создаёт новый DEK, соль, шифрует DEK через KEK текущей платформы и сохраняет `keys.dat`.
* `LoadKeyFile(string password)`
  * Читает `keys.dat`, восстанавливает параметры Argon2id из файла, расшифровывает DEK и затем нормализует ключевой файл под текущую платформу, если параметры отличаются.
* `ClearLoadedKey()`
  * Очищает `_dek` и `_loadedPassword`, чтобы после блокировки нельзя было экспортировать или использовать ключ без повторного входа.
* `GetDEK()`
  * Возвращает загруженный DEK. Если ключ не загружен, выбрасывает `InvalidOperationException`.
* `ExportKeyFileForTransfer()`
  * Создаёт переносимую версию `keys.dat` для синхронизации профиля. Требует загруженный DEK и мастер-пароль активной сессии. Экспортируемый файл переупаковывается с `TransferArgonParameters`.
* `ChangePassword(string newPassword)`
  * Перешифровывает DEK новым мастер-паролем и сохраняет ключевой файл с параметрами текущей платформы.
* `replaceMasterPassword(string oldPassword, string newPassword)`
  * Загружает ключ старым паролем и затем вызывает смену пароля.

## Формат ключевого файла

Переносимый формат содержит:

1. `KeyFileMagic`
2. `MemorySize`
3. `Iterations`
4. `ParallelismDegree`
5. длину соли
6. длину зашифрованного DEK
7. соль
8. зашифрованный DEK

Старый формат без заголовка также читается: первые 16 байт считаются солью, остальные байты - зашифрованным DEK.

## Логика переноса профиля Windows -> Android

1. На Windows пользователь должен быть уже авторизован, чтобы `_dek` и `_loadedPassword` были доступны в памяти.
2. `TcpBridge` вызывает `ExportKeyFileForTransfer`.
3. `keyManager` не отдаёт исходный Windows `keys.dat`, а создаёт новый ключевой файл с переносимыми Android-параметрами Argon2id.
4. Android импортирует архив и просит пользователя снова ввести мастер-пароль.
5. После успешного `LoadKeyFile` Android расшифровывает DEK и сохраняет `keys.dat` уже со своими локальными параметрами.

## Правила использования

* `ExportKeyFileForTransfer` можно вызывать только после успешного входа в хранилище.
* После блокировки обязательно вызывать `ClearLoadedKey`, чтобы очистить DEK и мастер-пароль из памяти.
* Нельзя просто копировать `keys.dat` между платформами как локальный рабочий файл: для передачи нужно использовать `ExportKeyFileForTransfer`.
* При изменении параметров Argon2id нужно учитывать совместимость переноса профиля между Windows и Android.
