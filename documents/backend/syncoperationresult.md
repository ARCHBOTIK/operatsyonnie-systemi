# SyncOperationResult

## Назначение

`SyncOperationResult` хранит итог операции синхронизации базы между устройствами.

## Роль в системе

DTO-объект результата для `TcpBridge`. Позволяет UI понять, завершилась ли операция успешно, была ли отменена и какое сообщение нужно показать пользователю.

## Пространство имён / модуль

`SecurePassword`

Источник: `SecurePassword/SecurePassword/sql(rus)/NetworkProtocols/TcpBridge.cs`

## Зависимости

* `SyncTransferMode` - направление операции.

## Основные свойства

* `Success`
  * Тип: `bool`
  * Назначение: успешное завершение операции.
* `Cancelled`
  * Тип: `bool`
  * Назначение: операция была отменена пользователем или токеном отмены.
* `Message`
  * Тип: `string`
  * Назначение: пользовательское сообщение о результате.
* `Mode`
  * Тип: `SyncTransferMode`
  * Назначение: направление операции.

## Основные методы

Нет.

## Логика работы

`TcpBridge` создаёт экземпляры результата через внутренние методы `Success`, `Cancelled` и `Error`, а вызывающий код читает свойства объекта.

## Правила использования

* Для ошибок `Success` должен быть `false`.
* Для отменённых операций `Cancelled` должен быть `true`.
* `Message` должен быть пригоден для показа в интерфейсе.
