# ScreenLock

`ScreenLock` - простой класс блокировки по строковому паролю.

## Назначение

Класс хранит пароль в памяти и флаг состояния блокировки. Он не связан с текущим механизмом `VaultSessionService` и `MasterPasswordPage`.

## Поля

- `_isLocked` - текущее состояние блокировки;
- `_password` - пароль для снятия блокировки.

## Методы

### Конструктор

`ScreenLock(string password)` сохраняет пароль и создает объект в разблокированном состоянии.

### Lock

`Lock()` устанавливает `_isLocked = true`.

### Unlock

`Unlock(string input)` сравнивает входную строку с `_password`. При совпадении снимает блокировку и возвращает `true`, иначе возвращает `false`.

### GetStatus

`GetStatus()` возвращает текущее значение `_isLocked`.

## Ограничение

Пароль хранится в открытом виде, поэтому класс не должен использоваться как основной механизм защиты хранилища.
